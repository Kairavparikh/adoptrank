# AdoptRank for VS Code

Install the backend package with `pipx`, ensure `adoptrank` is on `PATH`, then run
`AdoptRank: Find for Workspace`, `AdoptRank: Find for Selection`, or
`AdoptRank: Open Repository Leaderboard` from the Command Palette. The extension
delegates safe context scanning and ranking to the same public CLI and Vercel API,
so IDE, terminal, and web behavior share one implementation.
